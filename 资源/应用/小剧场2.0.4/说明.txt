小剧场可以一直保存提示词反复使用，可以剧情生成 + 陪伴共读。可以先在左侧建立灵感卡片（写一些你想看的设定），让系统生成连载的剧情章节，可以一键发送卡片给char一起读。也可以直接在小剧场里探讨聊天室，可以邀请 AI 角色和你一起“追更”，对刚刚生成的剧情进行实时点评或吐槽。探讨结束后，可以一键将这段“共读回忆”提炼并永久写入角色的主记忆中，让它成为你们共同的经历。




在阅读和互动之外，小剧场还提供了一套完整的干预与自定义工具。如果对剧情走向不满意，可以随时使用“由我执笔”强行接管下一章的创作，或者直接修改、重绘当前内容。另外，应用支持在正文底部挂载特殊的“番外卡片”（如自动生成的弹幕、角色心声、书评等）；并且开放了极高的自定义权限，支持导入本地字体、壁纸、自定义 API 线路，以及通过正则面板和自定义 CSS 来彻底改造界面的排版与气泡样式，方便打造沉浸式的专属阅读环境。
